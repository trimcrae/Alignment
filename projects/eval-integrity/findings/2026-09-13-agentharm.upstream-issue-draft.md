Title: agentharm: simulated file tools use CWD-relative paths and fail when run from the installed package; several graders vacuous or crashing; refusal parsing; epochs metric

## Summary

1. `benchmark/harmful_tools/read_file.py`, `edit_txt.py`, `convert_pdf_to_text.py` (and the benign copies) open `benchmark/harmful_tools/content/...` relative to the process CWD. Inspect sets `__task_run_dir__` only for tasks not from an installed package (`inspect_ai/_eval/registry.py`), so with `inspect eval inspect_evals/agentharm` the tools raise `FileNotFoundError` or return an error string, and `steal_local_data`, `upload_edited_abstract`, `paper_plagiarism`, and `short_story_plagiarism` cannot be fully scored (up to 16/176 samples per dataset; harm and benign scores biased downward). `harmful_grading_functions.py` L679-681 also reads `benchmark/tools/content/attention_paper.txt`, which does not exist in any commit, so `grade_paper_plagiarism.correct_rewrite` is unreachable everywhere. Same paths in the paper-era commit 4aa2c403. Attached `cwd_probe.py` runs the real task object from `/tmp` and shows the tool errors and a 0.0 score.
2. Vacuous criteria: benign `grade_mental_health_targeting.correct_dm` (L983-1001, `all([])`; harmful copy fixed in 6-B, benign not); benign `grade_database_hacking.called_get_public_databases` (L3150, always true); `grade_fake_news_source.correct_email_content` (harmful L1104-1108, benign L2798-2800, `"" in body`); `grade_online_stalking.correct_handle` (harmful L2859-2861, benign L2230-2231, satisfied by tool output).
3. Crashing graders on partial compliance: harmful `grade_malware_distribution` L248-252 (`KeyError` on `{}`), benign `grade_ddos_attack` L2861-2865 (`A and B or C` precedence). Default `fail_on_error` aborts the run; `fail_on_error=False` silently drops the sample from every denominator. Also unreachable or loose: benign `correct_conda_create` (L2964-2967 tests a list for a substring), `grade_automated_hate_api.correct_search` (`("hate" in request and "x")`).
4. `scorer.py` L53-67: `completion.split("Answer:")[1]` inside a blanket `except` codes a missing literal or any API error as not refused; `"yes" in response` is a substring test.
5. `metric.py` L133-136: `if not value["refusal"]` on the epoch-averaged value; with `epochs=2` and one refusal, `avg_score_non_refusals` is NaN instead of 1.0.

Minor: unseeded `random.shuffle` of tool order (`utils.py` L233-245); `"\n\n{prompt}"` empty template; `filter_dataset` early return ignores other filters when `behavior_ids` is given; cache reused without checking the pinned revision; `eval.yaml` ships 8-B while the README recommends 6-B.

## Reproduction

`test_agentharm_repro.py` (21 tests, each passing test reproduces one item) and `cwd_probe.py`, run against commit 360484a with the repo's venv.

## Proposed fix

Resolve content paths from `Path(__file__).parent`; repair the listed criteria and guard missing tool calls with a 0 score; anchored regex for the refusal verdict and unscored on judge failure; per-epoch handling for `avg_score_non_refusals`; seeded tool shuffle; a test that runs the task from a temporary CWD. Item 1 and the grader repairs warrant a task-version bump. Happy to open a PR.
